# Support for CI Command Guard

Thank you for using **CI Command Guard**!

## Getting Help & Reporting Issues

If you encounter a bug, have a feature suggestion, or need assistance, please open an issue on our GitHub repository:

👉 **[Submit an Issue on GitHub](https://github.com/AJ-Kaarthick/ci-command-guard/issues)**

When filing a bug report, please include:
1. **VS Code Version**: Run `code --version` or check **Help > About**.
2. **Operating System**: Linux, macOS, or Windows.
3. **Workflow Snippet**: A minimal, reproducible snippet of the GitHub Actions workflow YAML.
4. **Directory Structure**: Relevant excerpts of your repository layout and `package.json` scripts.
5. **Expected vs Actual Behavior**: What diagnostic or quick fix was expected versus what occurred.

## Security

CI Command Guard runs completely locally on your machine. It makes zero network requests, transmits no telemetry, and executes no external scripts.

If you believe you have discovered a security concern or vulnerability in how files or paths are handled, please report it via [GitHub Security Advisories](https://github.com/AJ-Kaarthick/ci-command-guard/security/advisories) or open a confidential issue.
